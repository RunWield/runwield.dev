# Downloads

Mode: Operate. Help developers install Core and then add an optional host plugin.

## Direction contract

THESIS: Make the exact install commands easy to find and copy, with Core's prerequisite clear before plugin setup.

OWN-WORLD: Inherit the site's slate ground, mint links, Outfit typography, IBM Plex Mono command text, blue focus rings,
and existing header, footer, and command shells. No visual-system replacement.

STORY: Choose the quick installer, Homebrew, or GitHub binaries. Then add Codex or Claude Code with the host's native
commands. Existing plugin users can find migration guidance.

FIRST VIEWPORT: A left-aligned Downloads heading and introduction lead into Core installation. Desktop sections pair
a narrow explanation column with a wider command column; mobile reads in one column. Commands remain selectable and
copy buttons report success or manual-copy recovery without hiding the instructions.

FORM: A focused installation reference, directly specified by the request. No concept seed: this extends the existing
site with an explicitly scoped downloads surface. Display Claude commands separately because each is submitted alone.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

No new rasters or design tokens. Preserve the incumbent system; inspect desktop and mobile and verify clipboard success,
clipboard denial, navigation, and metadata. Do not deploy or commit without a new request.
